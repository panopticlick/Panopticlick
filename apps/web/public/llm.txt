# Panopticlick

> Panopticlick is an independent, open-source browser privacy testing and education site. It lets a visitor run browser fingerprint, WebRTC, DNS, tracker-blocker, and HSTS tests, inspect modeled advertising-auction results, and learn practical defenses. It is inspired by, but is not affiliated with or endorsed by, the Electronic Frontier Foundation (EFF).

Canonical site: [https://panopticlick.org/](https://panopticlick.org/)

Content language: English

Last reviewed: 2026-08-10

Interpretation notes:

- The browser scan and valuation run locally by default. Scan data is sent to Panopticlick storage only after explicit opt-in; AI chat and network-dependent tests are separate user-triggered features described in the privacy policy.
- Fingerprint uniqueness is a modeled estimate based on research-derived priors, not a measurement of current Panopticlick visitors. The reported "1 in N" value is an upper bound because the model assumes fingerprint components are independent.
- RTB results are educational simulations using fictional demand-side platform profiles and modeled CPM ranges. No real bid request or advertising auction occurs.
- Privacy tests describe what the current browser session exposes; they do not certify that a browser, blocker, VPN, or network is secure.

## Primary tools

- [Browser fingerprint test](https://panopticlick.org/): Run the main investigation and see the browser signals, modeled uniqueness, simulated advertising value, and defense summary.
- [Detailed fingerprint scan](https://panopticlick.org/scan/): Inspect canvas, WebGL, audio, fonts, screen, navigator, and other exposed signals in a redacted dossier.
- [WebRTC leak test](https://panopticlick.org/tests/webrtc/): Check the IP candidates WebRTC exposes in the current browser session.
- [DNS leak test](https://panopticlick.org/tests/dns/): Inspect which DNS resolver handles the test query and whether the result is consistent with the visitor's expected VPN or network path.
- [Ad and tracker blocker test](https://panopticlick.org/tests/blocker/): Test first-party bait resources that resemble common tracker paths without loading the real third-party trackers.
- [HSTS supercookie demonstration](https://panopticlick.org/tests/hsts/): Learn how HSTS state can be abused for persistent identification through an interactive demonstration.
- [RTB auction simulator](https://panopticlick.org/simulation/rtb/): Run an educational, modeled real-time bidding auction using the current browser fingerprint.

- [Privacy policy](https://panopticlick.org/privacy/): Authoritative description of local processing, optional storage, retention, deletion, network tests, and AI chat processing.
- [About Panopticlick](https://panopticlick.org/about/): Project identity, mission, independence from EFF, technology, and contact information.
- [Source code](https://github.com/Panopticlick/Panopticlick): Public implementation of the site, fingerprint SDK, valuation engine, and API.

## Tracking explanations and defenses

- [Browser fingerprinting explained](https://panopticlick.org/anatomy/fingerprinting/): Technical guide to canvas, WebGL, audio, fonts, and other fingerprinting signals.
- [Supercookies explained](https://panopticlick.org/anatomy/supercookies/): Guide to HSTS, favicon-cache, and ETag-based persistent tracking.
- [Behavioral tracking explained](https://panopticlick.org/anatomy/behavior/): Guide to mouse, keyboard, scroll, and interaction-pattern tracking.
- [Browser hardening guide](https://panopticlick.org/defense/hardening/): Practical privacy settings and defenses for major browsers.

## Advertising technology explainers

- [CNAME cloaking](https://panopticlick.org/simulation/cname/): How trackers can appear to be first-party services through DNS aliases.
- [Cookie syncing](https://panopticlick.org/simulation/cookie-sync/): How advertising platforms exchange identifiers to recognize the same browser.
